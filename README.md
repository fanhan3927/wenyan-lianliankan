# 文言文连连看

以游戏之心，习文言之道。一款离线可玩的文言文知识点配对小游戏。

## 快速开始

无需安装、无需联网、无需构建。直接双击打开 `index.html` 即可游玩。
（推荐 Chrome / Edge 浏览器，手机浏览器亦可。）

## 玩法

1. **选择题库**：三套预置题库——《论语》选段、《世说新语》选段、课内必背文言文（《陋室铭》《爱莲说》）。
2. **选择关卡**：每套题库 3 关，需依次通关解锁；每关 6 对「文言词汇 ↔ 现代释义」，限时 60 秒。
3. **连连看配对**：点击左侧文言词汇、再点右侧释义完成连线配对，正确消除、错误抖动复原，每次即时反馈（视觉 + 音效）。
4. **结算与进度**：通关后展示正确率、用时、星级；成绩与成就自动保存于浏览器本地（localStorage）。

## 成就系统

| 成就 | 达成条件 |
|------|----------|
| 初窥门径 | 完成任意一个关卡 |
| 小有所成 | 完成一个题库的全部关卡 |
| 倒背如流 | 完成全部题库的所有关卡 |
| 行云流水 | 无失误通关任意一关 |
| 争分夺秒 | 剩余时间过半时通关一关 |

## 技术说明

- 纯原生 HTML / CSS / JavaScript，零第三方依赖。
- 音效由 **Web Audio API 纯代码生成**（`js/audio.js`），无任何音频文件；浏览器要求首次点击后出声。
- 进度与成就存储在 `localStorage`（键 `wenyan-lianliankan-v1`），清除浏览器数据即重置。
- 星级规则：无失误通关 3★；失误 ≤ 2 次 2★；其余通关 1★。

## 项目结构

```
wenyan-lianliankan/
├── index.html      # 页面骨架（5 个界面）
├── css/style.css   # 水墨宣纸风格样式
└── js/
    ├── data.js     # 3 套题库 × 3 关 + 成就定义
    ├── audio.js    # Web Audio API 音效引擎
    ├── storage.js  # localStorage 进度/成就持久化
    └── app.js      # 路由、游戏逻辑、计时、连线、结算、成就
```
